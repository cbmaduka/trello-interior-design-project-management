
# Project Cards

## Overview

Project cards represent individual interior design projects managed within the Trello board. Each card contains the information, documentation, deadlines, and progress required to deliver a project successfully from initial enquiry to completion.

The implementation demonstrates how Trello cards can function as centralized project records, allowing project teams to manage all project-related information in one location.

---

## Card Structure

Each project card contains:

- Project title
- Labels
- Due date
- Project description
- Assigned member
- Custom fields
- Checklist
- Attachments
- Activity log
- Comments
- Cover image

---

## Sample Projects

The board includes a diverse range of residential and commercial interior design projects, including:

- Luxury residential interiors
- Apartment furnishing
- Office renovations
- Hotel reception redesign
- Restaurant interior upgrades
- Wellness centre fit-outs

This variety demonstrates Trello's flexibility in managing multiple project types within a single workspace.

---

## Business Value

Using project cards provides several operational benefits:

- Centralized project information.
- Improved task organization.
- Better collaboration among project stakeholders.
- Easier document management.
- Clear project ownership and accountability.
- Improved visibility into project progress.
