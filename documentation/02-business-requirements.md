
# Business Requirements

## Overview

Oak & Ivory Design Studio required a centralized project management solution to organize and monitor interior design projects from initial client enquiry through final project completion.

The objective was to replace fragmented project tracking methods with a structured, collaborative workspace that provides visibility into every stage of the project lifecycle.

---

## Business Challenges

Before implementing Trello, the business faced several operational challenges:

- Project information was scattered across emails, spreadsheets, and messaging applications.
- Limited visibility into project progress and task ownership.
- Difficulty monitoring project deadlines and milestones.
- Inconsistent communication between designers, contractors, and project managers.
- Project documentation was stored in multiple locations, making retrieval inefficient.
- Manual tracking increased the risk of missed deadlines and delayed project delivery.

---

## Business Requirements

The implementation needed to provide the following capabilities:

- Centralized project management.
- Standardized project workflow.
- Task assignment and ownership.
- Project categorization using labels.
- Deadline tracking.
- Project checklists.
- Custom project information fields.
- Document management.
- Workflow automation.
- Calendar-based scheduling.
- Visual project progress tracking.

---

## Proposed Solution

Trello was selected to provide a visual Kanban-based project management system that enables the design team to manage every project using standardized workflows, project cards, automation, and supporting documentation.

Each project progresses through predefined workflow stages, ensuring consistency, accountability, and improved collaboration across the team.

---

## Expected Business Benefits

The implementation delivers several operational improvements:

- Improved project visibility.
- Better collaboration across project teams.
- Consistent project documentation.
- Reduced administrative effort through automation.
- Improved deadline management.
- Standardized project delivery process.
- Enhanced reporting through board views and calendar scheduling.
