
# Board Setup

## Overview

A dedicated Trello board was created to provide a centralized workspace for managing interior design projects at Oak & Ivory Design Studio.

The board was designed to support the complete project lifecycle, allowing project managers and designers to monitor project progress, organize tasks, and collaborate efficiently within a single environment.

---

## Board Configuration

### Board Name

**Oak & Ivory Project Pipeline**

### Visibility

Workspace

### Project Type

Interior Design Project Management

---

## Board Purpose

The board serves as the central location for managing residential and commercial interior design projects from initial client enquiry through final project completion.

Each project is represented as an individual Trello card, while workflow lists represent the different stages of project delivery.

---

## Board Components

The implementation includes:

- Workflow Lists
- Project Cards
- Labels
- Due Dates
- Checklists
- Custom Fields
- Attachments
- Automation Rules
- Calendar View
- Workspace Integration

---

## Business Value

Implementing a dedicated project board provides several operational benefits:

- Centralizes project information.
- Improves project visibility.
- Simplifies project tracking.
- Supports collaboration between team members.
- Provides a standardized project management process.
- Reduces reliance on spreadsheets and manual tracking.
