
# Project Overview

## Project Name

**Oak & Ivory Design Studio – Trello Project Management Implementation**

---

## Overview

This project demonstrates the implementation of Trello as a project management platform for Oak & Ivory Design Studio, a boutique interior design firm specializing in residential and commercial interior design projects.

The implementation was designed to centralize project management, improve collaboration, increase visibility across active projects, and provide a structured workflow from initial client enquiry through project completion.

Rather than relying on spreadsheets, emails, and manual tracking, the company now manages every project within a single Trello board using standardized workflows, custom fields, automation, checklists, project documentation, and calendar views.

---

## Business Scenario

Oak & Ivory Design Studio manages multiple design projects simultaneously, including residential homes, luxury apartments, commercial offices, hotels, cafés, and wellness centres.

Prior to implementation, project information was spread across multiple communication channels, resulting in inconsistent tracking, missed deadlines, and limited visibility into project progress.

This implementation provides a centralized workspace where designers, project managers, and stakeholders can monitor every stage of a project from enquiry to final handover.

---

## Project Objectives

- Implement a centralized project management system.
- Standardize the project delivery workflow.
- Improve collaboration among project stakeholders.
- Track project deadlines and milestones.
- Organize project documentation.
- Improve visibility into project progress.
- Demonstrate a real-world Trello implementation suitable for portfolio presentation.
