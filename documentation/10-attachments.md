
# Project Attachments

## Overview

Project documentation was centralized within Trello by attaching all key project files directly to the project card. This ensured that every team member could access important project information from a single location throughout the project lifecycle.

---

## Attached Project Documents

The following project assets were attached to the Trello card:

- Client Brief
- Concept Floor Plan
- Interior Design Mood Board
- Furniture Schedule

These documents provide the design team with the information required to plan, execute, and complete the project.

---

## Benefits

Centralizing project documents within each card provides several operational advantages:

- Easy access to project documentation.
- Reduced reliance on external file sharing.
- Improved collaboration between stakeholders.
- Better document organization.
- Faster onboarding for new team members.

---

## Business Value

Using Trello attachments creates a single source of truth for project information, reducing lost documents and ensuring that all stakeholders work from the latest project files.
