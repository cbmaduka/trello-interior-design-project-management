
# Card Cover

## Overview

Card covers were configured to provide a visual representation of each project directly on the Trello board. Rather than displaying text-only cards, project documents were used as card covers to make projects easier to identify and navigate.

For the featured luxury penthouse project, the project documentation was selected as the card cover to provide an immediate visual summary of the project's deliverables.

---

## Card Cover Configuration

A cover image was assigned to the project card using one of the attached project documents.

This configuration enables users to:

- Visually distinguish projects.
- Identify important projects at a glance.
- Improve board readability.
- Create a more engaging project dashboard.

---

## Business Value

Using card covers improves project visibility and creates a more intuitive user experience, especially when managing multiple projects simultaneously. Visual cards reduce the time required to locate projects and provide quick contextual information for project stakeholders.
